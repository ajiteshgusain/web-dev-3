# Smart Utility Toolkit

## Web Development 3 – Lab Assignment 1

A Node.js command-line based utility toolkit developed using Node.js core modules.

---

## 📌 Project Description

The Smart Utility Toolkit is a collection of small backend utilities created to understand the fundamentals of Node.js.

The project demonstrates:

- Command-line arguments
- Custom modules
- HTTP server creation
- File handling
- Random number generation
- Console logging
- Error handling
- Modular and reusable programming

Only Node.js built-in modules are used. No external npm packages are required.

---

## 🛠️ Technologies Used

- Node.js
- JavaScript (ES6)
- Command Prompt / PowerShell
- Node.js Core Modules:
  - `process`
  - `http`
  - `fs`
  - `crypto`
